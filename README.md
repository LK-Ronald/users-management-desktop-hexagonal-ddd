# users-management-desktop-hexagonal-ddd

Ejemplo de una aplicación Desktop que hace CRUDL y control de acceso de Usuarios, escrita en Java, arquitectura Hexagonal y enfoque DDD, usando buenas practicas y Clean code.

## Versión 1.6.0

En esta versión se integró el soporte interactivo de consola para la entidad Productor:

- Se implementó la visualización e interacción con el usuario en la interfaz de consola (CLI).

- Se agregaron las opciones CRUDL para productores directamente al menú principal (Listar todos los productores, Buscar productor por ID, Crear productor y Eliminar productor).
